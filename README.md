# خادم إشعارات طوبى (Cloudflare Worker)

يُرسل إشعار التذكير في الوقت الذي يختاره المستخدم (صباحًا و/أو مساءً) حتى لو كان التطبيق مغلقًا.
يعمل على نفس دومين الموقع: `toobaapp.com/api/*`.

## النشر (مرة واحدة، حوالي 10 دقائق)

> المطلوب: Node.js مثبّت، وحساب Cloudflare الذي عليه دومين toobaapp.com.

افتح الطرفية داخل مجلد `tooba-push` ونفّذ بالترتيب:

1. تسجيل الدخول:
   `npx wrangler login`

2. إنشاء قاعدة البيانات، ثم انسخ `database_id` من الناتج وضعه في `wrangler.toml` مكان «ضع_المعرّف_هنا»:
   `npx wrangler d1 create tooba-push`

3. إنشاء الجداول:
   `npx wrangler d1 execute tooba-push --remote --file=schema.sql`

4. توليد مفاتيح التشفير (VAPID)، وسيطبع قيمتين:
   `node generate-vapid.mjs`

5. حفظ القيمتين كأسرار (يطلب منك لصق القيمة في كل مرة):
   `npx wrangler secret put VAPID_PUBLIC`
   `npx wrangler secret put VAPID_PRIVATE`
   ⚠️ المفتاح الخاص سرّي، لا تضعه في Git ولا ترسله لأحد.

6. النشر:
   `npx wrangler deploy`

7. التحقق: افتح `https://toobaapp.com/api/key` في المتصفح، ولازم يظهر نص طويل (المفتاح العام).

بعدها ارفع `index.html` و`sw.js` (الإصدار 1.58) على Git كالمعتاد.

## التجربة
1. ثبّت التطبيق على جوالك (على آيفون لازم من الشاشة الرئيسية).
2. افتحه، واضغط أيقونة الجرس، واختر وقتًا بعد دقيقتين، واضغط «تفعيل التذكير بالإشعارات» ووافق على الإذن.
3. اقفل التطبيق وانتظر الإشعار.

## ملاحظات
- متابعة السجلات لحظيًا: `npx wrangler tail`.
- الباقة المجانية تسمح بحوالي 45 إشعارًا في الدقيقة الواحدة (حد Cloudflare لعدد الطلبات الخارجية). لو زاد المشتركون على الأوقات الشائعة (مثل 6:00)، انتقل لباقة Workers المدفوعة (حوالي 5$ شهريًا) وارفع `MAX_PER_RUN` في `src/index.js`.
- لا تُحفظ أي بيانات شخصية: فقط رابط اشتراك الجهاز، ووقتا التذكير، والمنطقة الزمنية. ويُحذف الاشتراك عند إيقاف التذكير أو إذا ألغى المتصفح الاشتراك.
- نص الإشعار ثابت ويُحدَّد من التطبيق نفسه: قبل الساعة 3 عصرًا بتوقيت الجهاز = أذكار الصباح، وبعدها = أذكار المساء.
